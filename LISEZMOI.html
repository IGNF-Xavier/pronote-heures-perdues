Suivre les heures de cours de son enfant avec Pronote
Mode d'emploi pas à pas, sans connaissance en informatique (version 0.9)

Outil non officiel, sans lien avec Index Éducation (éditeur de Pronote), la FCPE ou l'Éducation nationale.

L'outil pronote_suivi regarde l'emploi du temps de votre enfant dans Pronote (espace Parents), semaine après semaine, depuis la rentrée. Pour chaque semaine il prend une photo de l'écran, puis il fabrique un tableau Excel qui compte les heures prévues, les heures perdues (professeur absent, cours annulé, grève…) et les heures rattrapées, matière par matière.

Combien de temps ? La préparation (étapes 1 à 5) se fait une seule fois et prend environ 15 minutes. Ensuite, obtenir un nouveau tableau prend 3 à 5 minutes (étapes 6 à 8).

Ce qu'il vous faut

  • Un ordinateur sous Windows 10 ou 11 relié à Internet.
  • Le navigateur Microsoft Edge (déjà présent sur Windows) ou Google Chrome.
  • Vos identifiants Pronote de parent (ou ceux de l'ENT de l'établissement). Vous les taperez vous-même, l'outil ne les enregistre pas.
  • Excel, ou le logiciel gratuit LibreOffice, pour ouvrir le résultat.

1Ranger le dossier de l'outil

  1. Téléchargez pronote_suivi-0.9.zip depuis la page des versions.
  2. Si vous avez reçu un fichier .zip : ouvrez votre dossier Téléchargements, faites un clic droit sur le fichier, choisissez Extraire tout…, puis Extraire.
  3. Placez le dossier pronote_suivi à un endroit facile à retrouver, par exemple Documents ou Téléchargements.
  4. Ouvrez ce dossier. Vous devez y voir :
Fichier (l'extension peut être masquée)À quoi il sert
LISEZMOI.htmlCe mode d'emploi.
lancer.batLe bouton « démarrer » : on double-clique dessus.
parametres.iniVos réglages (facultatif de le modifier).
pronote_suivi.pyLe programme. Ne pas le modifier.
requirements.txtLa liste des compléments à installer (étape 5).

2Ouvrir l'invite de commandes (« la fenêtre noire »)

L'invite de commandes, appelée aussi cmd, est une fenêtre noire dans laquelle on écrit des instructions. On tape (ou on colle) une ligne, puis on appuie sur la touche Entrée.

La méthode la plus simple : l'ouvrir directement dans le bon dossier

  1. Ouvrez le dossier pronote_suivi dans l'Explorateur de fichiers.
  2. Cliquez dans la barre d'adresse en haut de la fenêtre (là où est écrit le chemin du dossier). Le texte devient bleu.
  3. Tapez cmd à la place, puis appuyez sur Entrée.

La fenêtre noire s'ouvre et la ligne se termine par le nom du dossier, par exemple :

C:\Users\VotreNom\Downloads\pronote_suivi>

Autre méthode

  1. Appuyez sur la touche ⊞ Windows du clavier, tapez cmd, puis Entrée.
  2. Allez dans le dossier en collant la ligne ci-dessous (si le dossier est dans Téléchargements), puis Entrée :
cd /d "%USERPROFILE%\Downloads\pronote_suivi"

Si le dossier est dans Documents :

cd /d "%USERPROFILE%\Documents\pronote_suivi"
Copier / coller : dans cette page, cliquez sur le bouton Copier à droite d'une ligne. Dans la fenêtre noire, faites un clic droit (ou Ctrl + V) pour coller, puis appuyez sur Entrée. Copiez une seule ligne à la fois et attendez que la précédente soit terminée.

3Vérifier si Python est installé

Python est un logiciel gratuit qui permet de faire fonctionner l'outil. Dans la fenêtre noire, collez puis validez :

python --version
Ce qui s'afficheCe que ça veut dire
Python 3.10, 3.11, 3.12, 3.13 ou 3.14 (suivi d'un autre chiffre, ex. Python 3.13.17)Parfait. Passez directement à l'étape 5.
'python' n'est pas reconnu en tant que commande…Python n'est pas installé : faites l'étape 4.
Le Microsoft Store s'ouvre, ou un message parle du StorePython n'est pas installé : fermez le Store et faites l'étape 4.
Un numéro plus ancien (3.9 ou moins) ou plus récent (3.15 et au-delà)Installez la version de l'étape 4.

4Installer Python (si nécessaire)

  1. Ouvrez cette page du site officiel de Python : https://www.python.org/downloads/release/python-31317/
  2. Descendez jusqu'au tableau Files en bas de page et cliquez sur Windows installer (64-bit). Un fichier nommé python-3.13.17-amd64.exe se télécharge.
  3. Ouvrez ce fichier (dossier Téléchargements, double-clic).
  4. Important : en bas de la première fenêtre, cochez la case « Add python.exe to PATH ». Sans cela, la fenêtre noire ne trouvera pas Python.
  5. Cliquez sur Install Now. Si Windows demande l'autorisation, répondez Oui.
  6. Attendez le message Setup was successful, puis cliquez sur Close.
  7. Fermez la fenêtre noire, ouvrez-en une nouvelle (étape 2) et revérifiez :
python --version

Vous devez lire Python 3.13.17 (ou un autre numéro compris entre 3.10 et 3.14).

Si un autre numéro s'affiche encore (par exemple 3.15), remplacez dans toutes les lignes de ce mode d'emploi le mot python par py -3.13, et utilisez ces lignes au lieu du double-clic sur lancer.bat.

5Installer les compléments (une seule fois)

Dans la fenêtre noire ouverte dans le dossier de l'outil, collez puis validez :

python -m pip install -r requirements.txt

Beaucoup de lignes défilent pendant une à deux minutes. C'est terminé quand la ligne C:\…\pronote_suivi> réapparaît.

  • Successfully installed … ou Requirement already satisfied : tout va bien.
  • [notice] A new release of pip is available : simple information, ignorez-la.
  • Du texte contenant ERROR : vérifiez votre connexion Internet et que vous êtes bien dans le dossier de l'outil (voir En cas de problème).

Il n'y a pas d'autre navigateur à installer : l'outil utilise Edge ou Chrome déjà présents.

6Lancer l'outil et répondre aux questions

Double-cliquez sur lancer.bat dans le dossier. (Ou, dans la fenêtre noire du dossier :)

python pronote_suivi.py
Au premier double-clic, Windows peut afficher « Windows a protégé votre ordinateur », car le fichier vient d'Internet ou d'une autre personne. Si vous avez reçu l'outil d'une personne de confiance : cliquez sur Informations complémentaires, puis Exécuter quand même. Sinon, ne le lancez pas.

L'outil pose ses questions. Appuyer simplement sur Entrée accepte la réponse proposée entre crochets.

Question 1 : l'adresse de Pronote (seulement la première fois)

Exemple d'écran

Adresse de votre Pronote (copiez-la depuis votre navigateur, puis collez-la ici)
   [Entrée = ouvrir un navigateur vide, par exemple pour passer par votre ENT] :
  • Dans votre navigateur habituel, ouvrez Pronote comme d'habitude, cliquez dans la barre d'adresse tout en haut, puis faites Ctrl + C (copier).
  • Revenez à la fenêtre noire, faites un clic droit (coller), puis Entrée. L'adresse ressemble à https://XXXXXXXX.index-education.net/pronote/parent.html.
  • Vous passez par l'ENT de la région ou du collège ? Appuyez juste sur Entrée : vous irez sur l'ENT vous-même dans le navigateur qui s'ouvre.

L'adresse saisie est mémorisée : la question ne revient plus.

Si cette question n'apparaît pas, c'est qu'une adresse est déjà enregistrée dans parametres.ini. Vérifiez que c'est bien celle de votre établissement (voir Les réglages) ; pour la ressaisir, effacez ce qui suit url =.

Question 2 : la date de la rentrée

Date de la rentrée (début de l'analyse) ?
   [Entrée = 31/08/2026]  ou tapez une date JJ/MM/AAAA :

Entrée pour garder le 31/08/2026. Sinon tapez la date sous la forme jour/mois/année, avec les barres : 01/09/2026.

Question 3 : jusqu'à quelle semaine ?

Jusqu'à quelle semaine ? Par défaut la semaine d'aujourd'hui (semaine du 23/11/2026).
   [Entrée = 27/11/2026]  ou tapez une date JJ/MM/AAAA :

Entrée pour aller jusqu'à la semaine d'aujourd'hui. Sinon tapez n'importe quel jour de la dernière semaine voulue, par exemple 16/10/2026.

7Se connecter à Pronote, puis laisser faire

  1. Une nouvelle fenêtre de navigateur s'ouvre. Dans cette fenêtre-là (pas dans votre navigateur habituel) :
    • connectez-vous avec vos identifiants de parent (ou via l'ENT) ;
    • choisissez votre enfant si vous en avez plusieurs ;
    • ouvrez Vie scolaire → Emploi du temps ;
    • attendez que la grille de la semaine soit entièrement affichée, avec la ligne de numéros de semaines au-dessus.
  2. Revenez à la fenêtre noire et appuyez sur Entrée.
  3. Ne touchez plus au navigateur. L'outil clique tout seul sur chaque semaine (quelques secondes par semaine) et la fenêtre noire l'indique :
Bande des semaines détectée (44 semaines d'école).
[sem.  1] 31/08/2026 -> 21 cours détectés
[sem.  2] 07/09/2026 -> 28 cours détectés
...
11 semaine(s) capturée(s).

Excel : C:\...\pronote_suivi\sortie\pronote_analyse_20261127.xlsx

Quand le message Appuyez sur une touche pour continuer apparaît, c'est fini : vous pouvez fermer la fenêtre. Les semaines de vacances ne sont pas listées, c'est normal. Pour tout arrêter en cours de route : Ctrl + C dans la fenêtre noire.

8Lire le résultat

Dans le dossier pronote_suivi, ouvrez le dossier sortie, puis le fichier pronote_analyse_…xlsx (le plus récent). Les onglets sont en bas de la fenêtre Excel :

OngletCe que vous y lisez
SynthèseL'essentiel : heures prévues, heures perdues (par motif), heures rattrapées, solde et pourcentages.
Saisie FCPECe qu'il faut taper dans l'outil de la FCPE (voir plus bas).
Justificatifs FCPELa liste, cours par cours, avec la photo correspondante.
Par matièreUne ligne par matière avec un TOTAL, et deux graphiques : les heures prévues (en bleu ce qui a été assuré, en rouge ce qui a été perdu, total écrit à droite de chaque barre) et la part perdue en %. Le petit tableau gris à droite sert aux graphiques : les #N/A qu'il contient sont normaux.
Par semaineLa même chose, semaine par semaine.

La fois suivante, refaites seulement les étapes 6, 7 et 8.

Déclarer les cours non assurés à la FCPE (facultatif)

La FCPE, fédération de parents d'élèves, propose l'outil en ligne Ouyapacours, ouvert aux parents, adhérents ou non : https://ouyapacours.fcpe.asso.fr/. L'onglet Saisie FCPE du tableau Excel reprend les rubriques de son formulaire.

  1. Sur le site, créez votre compte ou connectez-vous, puis ouvrez le formulaire de déclaration.
  2. Choisissez votre Enfant. Vérifiez Ville / code postal, Etablissement et Classe (en haut de l'onglet Excel).
  3. Dans l'onglet Excel, prenez la déclaration n° 1 : saisissez sa Matiere, puis la première ligne : Date et Duree.
  4. Pour chaque ligne suivante de la même déclaration, cliquez sur + Ajouter des heures et saisissez la date et la durée.
  5. Cliquez sur Valider, puis notez la date du jour dans les cases jaunes Saisi le. Passez à la déclaration suivante.
  6. La colonne Après validation indique s'il faut revenir sur le site signaler la fin du non-remplacement (les cours ont repris) ou, plus tard, sa prolongation.

Les photos justificatives sont dans sortie\captures_fcpe\ (un sous-dossier par tableau) : le bandeau du haut, avec les noms et la photo, est retiré et les cours concernés sont entourés en rouge. Les noms des professeurs restent visibles dans la grille.

  • Seuls les cours « Prof absent » sont retenus par défaut. Pour ajouter par exemple les cours annulés ou la grève : réglage motifs_fcpe, puis refaites le tableau.
  • La durée est en heures entières (un cours de 55 minutes compte 1 h). Les cours rattrapés, les matières exclues et les cours à venir ne sont pas comptés.
  • Les onglets FCPE sont figés : après une correction dans Détail, ils ne changent pas.
  • La fois suivante, un nouveau tableau reprend toutes les dates depuis la rentrée : comparez avec les cases Saisi le du précédent et n'ajoutez que les nouvelles dates à vos déclarations, pour ne rien compter deux fois.

Les réglages (fichier parametres.ini)

Vous n'avez normalement rien à modifier. Pour changer un réglage :

  1. Clic droit sur parametres.ini → Modifier dans le Bloc-notes (ou Ouvrir avec → Bloc-notes).
  2. Changez uniquement ce qui se trouve après le signe =. Les lignes qui commencent par ; sont des explications.
  3. Enregistrez avec Ctrl + S, puis fermez.

matieres_excluesMatières visibles dans le tableau mais non comptées dans les totaux ni les graphiques. Par défaut VIE DE CLASSE (créneau réservé mais rarement utilisé). Séparer par des points-virgules, écrire comme dans Pronote. Vide = tout compter.
ville, etablissement, classeRecopiés en haut de l'onglet « Saisie FCPE ». Ex. classe = 4ème

Comprendre les chiffres

CatégorieCe que Pronote indique sur le coursComptée comme
Prof absent« Prof. absent », « enseignant absent »heure perdue
Annulé« Cours annulé »heure perdue
Grèvele mot « grève » apparaît sur le coursheure perdue
Dispensé / Absence élève« dispensé », « absence »heure perdue
Déplacé/Modifié« Cours déplacé », « Cours modifié »heure rattrapée
Remplacé« Remplacement »cours assuré par un autre professeur (information)
Sortie/Événement« sortie », « voyage », « événement », « stage »information
Maintenurien de particulier, ou « changement de salle »cours normal
  • Heures prévues : les heures de l'emploi du temps, sans les créneaux ajoutés pour un rattrapage.
  • Heures perdues : professeur absent + annulé + grève + dispensé + absence.
  • Heures rattrapées : cours déplacés ou modifiés.
  • Solde net : rattrapées − perdues. Un nombre négatif = des heures réellement perdues.
  • % perdu brut : perdues ÷ prévues. % perdu net : après déduction des rattrapages.
  • La durée est celle indiquée par Pronote : un cours de 55 minutes compte pour 0,92 heure.
  • Une grève n'est reconnue que si Pronote l'écrit ; sinon l'heure apparaît comme « Prof absent » ou « Annulé ».
  • Les rattrapages qui n'apparaissent pas dans l'emploi du temps Pronote ne sont pas comptés.

Matières non comptées (Vie de classe par défaut) : elles restent visibles dans Détail et, en gris, dans Par matière. La Synthèse rappelle ce qui est exclu. Pour exclure un seul cours, passez sa case « Inclus dans les calculs ? » à Non dans Détail.

Refaire le tableau sans se reconnecter à Pronote

Après avoir changé un réglage (par exemple les matières exclues), on peut refaire le tableau à partir des semaines déjà enregistrées. Dans la fenêtre noire du dossier :

python pronote_suivi.py --etape analyse

Confidentialité

  • L'outil ne lit ni n'enregistre votre mot de passe : vous vous connectez vous-même dans le navigateur.
  • Tout reste sur votre ordinateur ; seuls les échanges habituels avec Pronote (ou l'ENT) passent par Internet.
  • Le dossier sortie\profil_navigateur garde la trace de votre connexion : supprimez-le après usage, surtout sur un ordinateur partagé.
  • Les photos et le tableau contiennent le nom de votre enfant, ses matières et ses professeurs : ne les diffusez pas sans précaution.
  • Avant de transmettre l'outil à quelqu'un : retirez tous les dossiers sortie… et effacez dans parametres.ini ce qui suit url =, ville =, etablissement = et classe =.
